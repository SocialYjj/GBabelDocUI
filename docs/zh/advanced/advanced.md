# Web UI 设置

本页描述 GBabelDocUI，不是上游 `pdf2zh_next` 命令行参数的复制文档。

## 翻译服务

设置页提供 OpenAI、Azure OpenAI 和 Google Gemini。填写模型或部署名称、API 密钥及对应端点字段。API 密钥留空会保留服务端已保存的值。

## 语言和页码

- 源语言：自动检测、英语、中文、日语、韩语、法语、德语、西班牙语和俄语。
- 目标语言：英语、中文、日语、韩语、法语、德语、西班牙语和俄语。
- 页码可选择全文，或填写经过校验的逗号分隔页码与范围，例如 `1,3,5-8`。

## PDF 输出

可生成单语和双语 PDF，选择译文在前或交替页面，只保留已翻译页，并设置水印模式。至少需要保留一种 PDF 输出。

## 高级翻译和 PDF 行为

支持自定义系统提示词、最短文本长度、主字体、术语提取、文档布局端点、兼容性选项、OCR 处理、表格翻译、短行拆分、公式模式和部分 BabelDOC 阈值。

自定义端点由服务端校验。默认只允许公共 HTTPS 端点；可信部署需要访问私网或回环端点时，由管理员设置 `GBABELDOCUI_ALLOW_PRIVATE_ENDPOINTS=true`。

## 请求频率

- RPM 模式：每分钟 60–1200 次请求，并发线程 1–64。
- 自定义模式：QPS 1–20，worker 0–64。
- 术语提取有独立的服务和限流设置。

服务端会再次校验这些数值，并执行单用户和全局活动任务上限，不能通过修改前端绕过。

## 保存设置

设置按用户保存，任务启动时获得去除敏感字段的快照。API 密钥不会返回浏览器，也不会写入任务历史。
