# 语言代码

当前 Web UI 提供以下语言选项。

| 代码 | 语言 | 源语言 | 目标语言 |
| --- | --- | :---: | :---: |
| `auto` | 自动检测 | 是 | 否 |
| `en` | 英语 | 是 | 是 |
| `zh` | 中文 | 是 | 是 |
| `ja` | 日语 | 是 | 是 |
| `ko` | 韩语 | 是 | 是 |
| `fr` | 法语 | 是 | 是 |
| `de` | 德语 | 是 | 是 |
| `es` | 西班牙语 | 是 | 是 |
| `ru` | 俄语 | 是 | 是 |

翻译服务和 BabelDOC 内部可能支持更多代码，但当前 Web UI 边界不会接受未提供的值。
