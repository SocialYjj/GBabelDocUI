# 开始使用

GBabelDocUI 支持通过 Docker Compose 或本地 `uv` 环境安装，实际操作通过 Web UI 完成。

## 受支持的方式

1. [Docker Compose](./INSTALLATION_docker.md)
2. [uv](./INSTALLATION_uv.md)
3. [Web UI](./USAGE_webui.md)

## 上游参考资料

Windows EXE 和命令行页面描述的是官方 `pdf2zh-next`，不是 GBabelDocUI；其命令和界面不能与 `gbabeldocui` 互换。

- [上游 Windows EXE 参考](./INSTALLATION_winexe.md)
- [上游命令行参考](./USAGE_commandline.md)
