# 常见问题

## 为什么启动后没有自动打开浏览器？

`gbabeldocui` 只启动服务，不会打开浏览器。请手动访问 `http://127.0.0.1:7860/login.html`。

## 为什么本机 HTTP 登录后又回到登录页？

默认启用 Secure Cookie。本机回环 HTTP 需要在启动前设置 `GBABELDOCUI_COOKIE_SECURE=false`；公开部署必须使用 HTTPS 并保持为 `true`。

## 为什么不能远程创建首个管理员？

默认只允许本机初始化。可信环境必须远程初始化时，设置一次性高强度 `GBABELDOCUI_SETUP_TOKEN`，完成后移除并重启服务。

## 多个 worker 或容器能否共享一个数据目录？

不能。每个 `data/` 目录只允许一个进程和一个副本，第二个实例会快速失败，避免破坏任务状态。

## 服务重启后任务如何处理？

任务状态和历史保存在 SQLite。启动时会收尾未完成任务，完成、失败和取消记录按保留期清理。

## 为什么重新打开设置后 API 密钥为空？

已保存的密钥不会返回浏览器。留空保存表示保留原密钥，填写新值才会替换。

## 上传和结果保存在哪里？

默认位于 `data/users/<username>/`。其中可能包含密钥和私有文档，禁止提交或公开。

## 如何更新？

源码安装执行 `git pull --ff-only` 后运行 `uv sync --frozen`；Compose 部署更新源码后运行 `docker compose up -d --build`。重大操作前应停止服务并备份受保护的数据目录。

## 为什么上传返回 HTTP 413？

请求超过 `GBABELDOCUI_MAX_UPLOAD_BYTES` 或流式请求体上限。提高限制也会增加存储和处理风险，公开部署应保持有界。
