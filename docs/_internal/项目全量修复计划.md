# GBabelDocUI 项目全量修复计划

## 目标

基于 2026 年 8 月 9 日、提交 `e178bc77c7084233d0eb1e3fd2fe6fc4dc3fa3f3` 的全量审查结果，修复已复现缺陷和可在仓库内解决的后端、前端、持久化、依赖、容器、CI、文档及许可证问题，并补充对应测试和发布验证。

## 已确认的设计决策

- 认证改为 `HttpOnly`、`Secure`、`SameSite` Cookie，并增加 CSRF 防护；不再将会话令牌持久化到 `localStorage`。
- 修改密码后撤销全部会话，前端立即回到登录页。
- 完成、失败和取消任务及其输出默认保留 90 天，可由环境变量调整。
- 升级后的首次保留期清理设置宽限期，不在本次开发和测试中读取或删除现有 `data` 内容。
- 设置页只显示能够完整配置的 OpenAI、Azure OpenAI 和 Google Gemini；其他提供商暂不在界面暴露，后端兼容能力不通过额外模式参数扩散。
- 当前运行模型明确限定为单实例；共享数据目录的第二个实例应快速失败，而不是修改其他实例任务状态。
- 只修复审查范围内的问题，不保留失效旧逻辑或无意义兼容代码。
- 网络与安全测试只采用防御性验证，不生成可直接滥用的测试载荷。

## 阶段计划

### 阶段一：输入边界、认证与会话

状态：已完成

完成情况：输入校验、Cookie 会话、CSRF、登录限流、会话撤销、管理员初始化边界和远程端点校验均已实现，并由认证及接口测试覆盖。

- 拒绝非有限浮点数。
- 统一页数拆分与官方引擎契约。
- 完整解析页码范围并结合 PDF 页数校验。
- 限制公式正则长度、复杂度和执行时间，避免无界缓存输入。
- 修复上传取消后的部分文件清理。
- 消除密码修改与登录的并发竞态。
- 修复登录后二次会话校验返回空值时的 500。
- 自定义端点校验覆盖 DNS 解析结果、重定向和 HTTPS 边界。
- 初始化管理员增加一次性启动凭据或仅本机初始化边界。
- 认证改为 Cookie 和 CSRF 模型。

### 阶段二：持久化、任务生命周期与资源边界

状态：已完成

完成情况：SQLite 已成为任务和历史记录的唯一事实源；旧历史采用一次性记账迁移。任务收尾、保留期、路径相对化、单实例锁、资源上限、失败重试和阻塞操作调度均已实现。

- 任务设置快照排除 API 密钥等敏感字段。
- 增加任务、输出和历史保留期及升级宽限期。
- 删除无界 `history.json` 全量同步，SQLite 作为唯一任务事实源；只保留明确导出能力。
- 修复损坏旧历史反复迁移问题。
- 修复任务取消、失败和超时的状态收尾。
- 增加数据目录单实例锁。
- 用户删除失败进入可恢复状态，不返回虚假成功。
- 持久化路径改为数据目录相对路径。
- 收紧普通用户并发、QPS、RPM、页数和文档复杂度上限。
- 补齐设置字段类型和长度验证。
- 将阻塞式 bcrypt、SQLite 和文件锁操作移出事件循环。
- 改进登录限流、会话数量限制和数据库索引。

- 前端在提交前校验数字、页码和正则字段。

- 增加历史分页。
