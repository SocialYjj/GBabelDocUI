# 시작하기

GBabelDocUI에서 지원하는 설치 방식은 Docker Compose 또는 uv를 사용한 로컬 설치이며, 사용은 Web UI에서 진행합니다.

## 지원 방식

1. [Docker Compose](./INSTALLATION_docker.md)
2. [uv](./INSTALLATION_uv.md)
3. [Web UI](./USAGE_webui.md)

## 업스트림 참고 문서

Windows EXE와 명령줄 페이지는 공식 pdf2zh-next 설명이며 GBabelDocUI 설명이 아닙니다. 명령은 서로 호환되지 않습니다.

- [Windows EXE reference](./INSTALLATION_winexe.md)
- [Command-line reference](./USAGE_commandline.md)
