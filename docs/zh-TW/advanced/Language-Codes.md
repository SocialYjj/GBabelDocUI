# 語言代碼

目前 Web UI 提供以下語言選項。

| 代碼 | 語言 | 來源語言 | 目標語言 |
| --- | --- | :---: | :---: |
| `auto` | 自動偵測 | 是 | 否 |
| `en` | 英文 | 是 | 是 |
| `zh` | 中文 | 是 | 是 |
| `ja` | 日文 | 是 | 是 |
| `ko` | 韓文 | 是 | 是 |
| `fr` | 法文 | 是 | 是 |
| `de` | 德文 | 是 | 是 |
| `es` | 西班牙文 | 是 | 是 |
| `ru` | 俄文 | 是 | 是 |

翻譯服務與 BabelDOC 內部可能支援更多代碼，但目前 Web UI 邊界不會接受未列出的值。
