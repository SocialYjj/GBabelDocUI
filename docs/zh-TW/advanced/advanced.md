# Web UI 設定

本頁說明 GBabelDocUI，而不是上游 `pdf2zh_next` 命令列參數的複製文件。

## 翻譯服務

設定頁提供 OpenAI、Azure OpenAI 與 Google Gemini。請填寫模型或部署名稱、API 金鑰及對應端點欄位。API 金鑰留空時，會保留伺服器端已儲存的值。

## 語言與頁碼

- 來源語言：自動偵測、英文、中文、日文、韓文、法文、德文、西班牙文與俄文。
- 目標語言：英文、中文、日文、韓文、法文、德文、西班牙文與俄文。
- 頁碼可選擇全文，或填寫經過驗證、以逗號分隔的頁碼與範圍，例如 `1,3,5-8`。

## PDF 輸出

可產生單語與雙語 PDF、選擇譯文在前或交替頁面、只保留已翻譯頁面，並設定浮水印模式。至少必須保留一種 PDF 輸出。

## 進階翻譯與 PDF 行為

支援自訂系統提示詞、最短文字長度、主要字型、術語擷取、文件版面配置端點、相容性選項、OCR 處理、表格翻譯、短行拆分、公式模式與部分 BabelDOC 閾值。

自訂端點由伺服器端驗證。預設只允許公用 HTTPS 端點；可信部署需要存取私有網路或回環端點時，必須由管理員設定 `GBABELDOCUI_ALLOW_PRIVATE_ENDPOINTS=true`。

## 請求頻率

- RPM 模式：每分鐘 60–1200 次請求，並行執行緒 1–64。
- 自訂模式：QPS 1–20，worker 0–64。
- 術語擷取具有獨立的服務與限流設定。

伺服器端會再次驗證這些數值，並套用單一使用者與全域作用中任務上限，無法透過修改前端繞過。

## 儲存設定

設定會依使用者分別儲存。任務啟動時會取得已移除敏感欄位的快照；API 金鑰不會傳回瀏覽器，也不會寫入任務歷史記錄。
