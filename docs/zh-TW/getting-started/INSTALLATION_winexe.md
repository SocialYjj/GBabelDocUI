# 上游 Windows EXE 參考

GBabelDocUI 不發布或內建 Windows EXE。受支援的安裝方式為 [Docker Compose](./INSTALLATION_docker.md) 與 [uv](./INSTALLATION_uv.md)。

需要上游獨立 Windows 套件時，請使用官方 [PDFMathTranslate-next Releases](https://github.com/PDFMathTranslate-next/PDFMathTranslate-next/releases) 與對應版本說明，不要將其視為 GBabelDocUI 的建置產物。
