# Language codes

GBabelDocUI currently exposes the following language choices in the Web UI.

| Code | Language | Source | Target |
| --- | --- | :---: | :---: |
| `auto` | Automatic detection | Yes | No |
| `en` | English | Yes | Yes |
| `zh` | Chinese | Yes | Yes |
| `ja` | Japanese | Yes | Yes |
| `ko` | Korean | Yes | Yes |
| `fr` | French | Yes | Yes |
| `de` | German | Yes | Yes |
| `es` | Spanish | Yes | Yes |
| `ru` | Russian | Yes | Yes |

The selected translation provider and BabelDOC may support additional codes internally, but unsupported values are not accepted through the current Web UI boundary.
