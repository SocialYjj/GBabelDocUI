# Primeiros passos

As formas suportadas de instalar GBabelDocUI são Docker Compose ou instalação local com uv; o uso é feito pela interface Web.

## Formas suportadas

1. [Docker Compose](./INSTALLATION_docker.md)
2. [uv](./INSTALLATION_uv.md)
3. [Web UI](./USAGE_webui.md)
